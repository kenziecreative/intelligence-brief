# Completion Criteria

Canonical, stable-ID completion criteria for this research project. This file is the
**canonical** form: the research plan's prose Success Criteria section is generated from it,
and the corpus-review validator rejects ID drift between the two. The corpus reviewer's C1
check must enumerate **every** ID below with a per-ID disposition (met / unmet /
waived-with-record) — a missing ID is insufficient coverage and blocks the gate.

Rules:
- IDs are stable (`SC-1`, `SC-2`, …) — never renumber; retire a criterion by marking it
  waived with a recorded rationale, never by deleting the line.
- One criterion per line, checkable: a criterion that cannot fail is not a criterion.
- Checkboxes here are working state for humans; the authoritative dispositions at close are
  the ones in the review receipt.
