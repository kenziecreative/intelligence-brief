# Phase 2: Recommendation

## Recommendation

Meridian should select **Helpdock at $14/user/mo** [Source: note-helpdock.md]. At 24
seats this is $336/mo — comfortably inside budget and confirmed across sources.

Both vendors support SSO, so security requirements do not differentiate the two; the
deciding factors are SLA and migration tooling.

Implementation is fast: Helpdock onboards teams like Meridian in **1 week**
[Source: note-helpdock.md], so the migration can land inside the current quarter.

## Rejected alternative

Replyline is cheaper ($11/user/mo) but carries no committed SLA
[Source: note-replyline.md].
